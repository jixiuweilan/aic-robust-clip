## W“常数缩放”的纠正

原报告第 5 节的“坐实常数缩放”结论不成立，也不是本轮必须修复的代码缺陷。

当前实现按 sample ID 更新逐样本损失 EMA，再在观测类别内排名，映射为 `w=0.2+0.8×(1-rank)`。类别内平均排名固定，因此平均权重固定为 0.6；权重被分给哪些样本可以变化。`class_mean_weight_min/max` 描述的是各类均值，不是每张图片的权重极值。`label_changes=0` 表示不改标签，不是权重变化计数。

本次用各类 `weight_sum`、`weight_square_sum` 和样本数独立重算方差及 ESS：第 2–10 轮，500 个类别的类内权重方差全部大于零，范围约 **0.05396065–0.05400000**。若每张图片权重都是 0.6，方差必须为零、ESS 必须等于类样本数，实际统计与此不符。第一轮结束后写出的全 1 权重属于 warmup；第二轮末统计供第三轮训练使用。

该实现的损失按权重总和归一化，统一乘一个常数还会在分子分母中抵消，不能把类均值 0.6 解读为 CE 整体缩小为 0.6 倍。实现对评分的响应以及恢复连续性已有合成回归覆盖；本次重建训练版本的完整 src 摘要，与服务器记录精确一致。

聚合统计无法说明第 3→6→10 轮究竟有哪些 ID 改变了权重。本轮第六/十轮 checkpoint 的逐 ID EMA/weights 未回传，仍不能量化真实跨轮演化；如需研究，只读导出已有 checkpoint 的这些状态即可，不需重新评分、训练或修改旧代码。W 当前设置效果较差可以作为降低优先级的依据，不能把这个判断写成“实现退化”或“所有 W 方法无效”。
